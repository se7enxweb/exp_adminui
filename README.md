# Exponential Admin UI (exp_adminui)

The Netgen Admin UI look and layout for the Exponential 6 administration, as the `adminui` design and siteaccess.
A port of the Netgen Admin UI Twig layout to Exponential template code; its stylesheets, fonts, images and
scripts are copied unchanged. Work in progress: see [doc/PROGRESS.md](doc/PROGRESS.md).
